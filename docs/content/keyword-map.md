# Keyword Map: EN · pt-PT · id

**Purpose:** decide which page targets which query, in which language, so Phase 2 pages don't cannibalise each other.
**Method (Oct 2026):** seed list from current copy (`app.js` problemMatrix, articles) and audit §5.2, then checked with live web searches to see real phrasing and who ranks. **No keyword tool data was available to this session.** Every volume below is an **estimate**: a relative band from search-result density, autocomplete-style phrasing and competitor coverage. Replace the bands with Google Search Console and Keyword Planner/Ahrefs/Semrush numbers after the first 4–8 weeks of Phase 2.

**Volume bands (estimated monthly searches, all variants, target country):**
`XS` < 50 · `S` 50–300 · `M` 300–1,500 · `L` 1,500–10,000 · `XL` > 10,000

**Priority:** `P1` build in Phase 2 launch · `P2` within 3 months · `P3` opportunistic.
**Intent:** `I` informational · `C` commercial investigation · `T` transactional (hire / book) · `N` navigational.

Target URLs refer to `site-architecture.md` §3. "Guide (cal. M#)" means the article is scheduled in `editorial-calendar.md` month #.

## 5. Cannibalisation rules

1. **Service vs guide:** Service pages target "jasa/serviço/help/service" and transactional modifiers. Guides target "cara/como/how to/what is". If GSC shows both ranking for the same query, strengthen the internal link from guide → service and de-optimise the guide's title.
2. **One pillar per topic per language.** NIF + NISS + AIMA share one pillar guide (existing article), and three cluster guides go deeper (AIMA documents, NISS online, bank).
3. **Visas:** the guide owns "visto Indonésia portugueses / Indonesia visa guide". The service owns "visa & KITAS help / apoio visto KITAS".
4. **"PT PMA" head term (EN/ID):** don't fight the large agencies. Always add the Portugal modifier in titles ("for Portuguese companies", "para empresas portuguesas").
